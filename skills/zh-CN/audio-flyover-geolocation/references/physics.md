## 1. 符号与精确关系

- τ：发射时刻（飞机发出声音）；t：接收时刻（麦克风听到）。
- R(τ)：观测点到飞机的斜距；Ṙ = dR/dτ（远离为正）。
- 传播：t = τ + R(τ)/c。
- 静止观测者、静止空气：

  f_obs(t) = f0 · dτ/dt = f0 / (1 + Ṙ(τ)/c)

关键：Ṙ 必须在**发射时刻**取值。若用接收时刻的 Ṙ（"现在飞机在哪"），得到的曲线不仅延迟，
而且**形状不同**——近距离、高速时尤其明显。脚本的 `doppler_from_track` 对任意采样轨迹精确计算
(t_rx, f, R)，打分阶段全用它。

## 2. 直线匀速飞越的闭式解

速度 v，CPA 斜距 d（3D 最小距离），t_c = CPA 时刻发出的声音被接收的时刻（此刻 f = f0）：

```
T  = t − (t_c − d/c)
s  = [c²T − sqrt(c²v²T² + d²(c² − v²))] / (c² − v²)      # s = τ − τ_cpa
R  = c (T − s)
Ṙ  = v² s / R
f  = f0 / (1 + Ṙ/c)
```
匀速爬升/下降的直线仍是 3D 直线，上式依旧成立（v 取 3D 速度，d 取 3D 最小距离）。

## 3. 由曲线读参数的恒等式

- 渐近线：f_hi = f0/(1 − v/c)，f_lo = f0/(1 + v/c)
- v = c (f_hi − f_lo)/(f_hi + f_lo)
- f0 = 2 f_hi f_lo/(f_hi + f_lo)（调和平均，不是算术平均）
- CPA 处斜率：df/dt = −f0 v²/(c d) ⇒ d = f0 v²/(c |slope|)
- 直观：**v 决定下降幅度，d 决定下降快慢**。

例（视频中的数值）：f0 = 130 Hz，v = 62.7 m/s，c = 343 m/s → f_lo = 130/(1+0.1828) ≈ 109.9 Hz。

谐波：追踪的是第 n 次谐波时 f0 → n·f0，v、d 不变（比值不含 f0）。

## 4. 误差与退化

- **c 的比例性**：v ∝ c，d ∝ c（d = f0 v²/(c|slope|)，v ∝ c ⇒ d ∝ c）。声速 2 % 误差 ⇒ v、d 各 2 %。
- **v–d 退化**：渐近线不清楚（尾部被噪声淹没、门控删掉、框截断）时，拟合沿 v²/d ≈ 常数滑动。
  例如真值 v=68.1、d=1422（k=3.26），拟合 v=59.8、d=1055（k=3.39）：v 偏 12 %，d 偏 26 %，k 只偏 4 %。
- 因此 `search_constraints` 输出：宽速度窗（默认 ±20 % + c 不确定度）、窄 **k 窗**（±8 % 或 3σ_k）、
  以及由两者推出的 d 窗 [v_min²/k_max, v_max²/k_min]。搜索时每架候选机用**自己的 ADS-B 地速**算
  k = gs²/d_cpa 并检查是否落入 k 窗——这比独立地卡 v 和 d 更准，也更不容易漏掉真值。
- tCPA 的不确定度通常 < 1 s。
- **拟合不确定度。** 相邻帧重叠（窗长/帧移），而真实飞越的残差相关得更久（转弯、功率变化、追踪器沿一条平滑的错误路径）。脚本测量残差相关时间 τ = 1 + 2·Σρ_k（累加到 ρ 低于 0.05），按 max(win/hop, τ) 放大协方差。二者不相乘，因为描述的是同一种相关。拟合输出含 `resid_corr_time`、`sigma_inflation` 和 `n_eff`。自测场景中 τ 为 3–38 个点，sigma 比只按重叠放大时最多再大 2.7×；直线合成飞越的 τ ≈ 2，结果不变。
- **sigma 只是统计误差。** CPA 前的加速让拟合 v 的偏差远超 sigma（自测事件 2 约 10 σ）。所以搜索依赖宽速度窗和 k 窗，而不是 sigma。`corr_v_d`（通常 0.8–0.9）表示 v 与 d 沿 k = v²/d 相互滑动的程度。

## 5. 声速、温度、风

- c = 20.0468 · √(T + 273.15)（干空气，m/s）；15 °C → 340.3，25 °C → 346.2。湿度影响 < 0.5 %。
- 温度来自 METAR/再分析数据（录音时刻、地面）。逆温层下近地温度与飞机高度温度不同，取路径平均更好；
  不确定时保留 `--c-uncert 0.04`。
- 均匀风 w：沿射线有效声速 c_eff = c + w·n（n 为源→观测者单位向量）。顺风侧/逆风侧不对称，
  会被误读为速度变化。强风（> 8 m/s）时放宽 `--d-margin` 并在报告中注明。

## 6. 非理想运动

| 运动 | 曲线表现 | 处理 |
|---|---|---|
| CPA 后转弯 | 一侧渐近线不平、残差左右不对称 | `fit` 给出 asymmetry note；打分阶段用真实航迹，转弯反而**消除镜像** |
| 加速/减速、爬升率变化 | 近、远两侧"表观速度"不同 | `fit_split`（两侧各一个 v）+ 窗口取并集；依赖 k 窗 |
| 盘旋/悬停（直升机） | 曲线可升可降 | `trace --no-monotone`；通常改用其他事件 |
| CPA 前转向麦克风 | 曲线先上升一段，再下降 | `trace --no-monotone`（默认追踪只留下一小段时 `trace` 会提示） |

## 7. 声源

- 螺旋桨 BPF = 桨叶数 × RPM / 60，谐波丰富。常见：C172（2 叶，2300–2700 rpm）70–90 Hz；
  PA-28 类似；涡桨 DHC-8-400（6 叶，~1020 rpm 巡航）≈ 102 Hz；ATR 72（6 叶，~1200 rpm 起飞/~990 巡航）≈ 100–120 Hz；
  King Air 350（4 叶，~1700 rpm）≈ 113 Hz。以上为量级参考，实际 RPM 随功率设定变化，不要据此硬过滤机型。
- 直升机主旋翼 BPF 10–25 Hz（手机麦克风常衰减），尾桨 50–120 Hz 更易用。
- 双发：两条接近但不同的线（转速不同步）→ 只追一条。
- 喷气机：宽带为主，偶有风扇音调（kHz 级，远处衰减大）；默认不作为事件，只用于静默判定。

## 8. 数值核对

`physics.doppler_linear` 与 `doppler_from_track` 在直线轨迹上应一致（误差 < 1e-6 Hz）。
`selftest` 中合成录音按精确发射时刻物理生成，可用来回归测试任何修改。
