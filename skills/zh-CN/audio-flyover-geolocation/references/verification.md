# 验证与置信度

声学结果是**假设**，不是结论。报告前至少完成 A 部分，并按 C 部分评级。

## A. 必做的声学自检

0. **追踪检验**：`best.trace_check.consistent` 必须为 true。两事件给出 `NO CONSISTENT SITE` 表示没有答案：报告这一点和 F 部分列出的原因，而不是得分最高的点。
1. **叠加图**（`result.rank1.<event>.png`）：青色模型曲线在接近段渐近线、CPA 陡降段、远离段渐近线
   三处都应压在亮线上。只贴合 CPA 段 = d、v 组合偶然吻合，置信度降一级。
2. **第 2、3 名叠加图**：如果它们看起来和第 1 名一样好，`margin` 再大也要谨慎。
3. **热图**（`result.heatmap.png`）：单峰、0.9 区域半径 ≤ 150 m 为好；条带状 → 看 `geometry` 与 `coarse_plateau`。
4. **录音起始时间**：`rec_start_iso` 与元数据/上传时间/画面中的时间线索是否一致（元数据常是导出时间，差几分钟到几小时都可能）。
5. **反证检查**：在最佳点上，录音时段内还有哪些 prop/rotor 航班近距离经过？脚本静默过滤已排除"应听到却没听到"，
   但应人工确认那些段落确实安静（不是被说话/风噪遮盖）。
6. **参数稳健性**：改变 `--c`（±2 %）、`--harmonics 1` vs `1,2`、`--lock e1`，最佳点应基本不动（< 100 m）。

## B. 独立（非声学）佐证

- **街景/卫星影像**：画面里的建筑、道路、植被、电线杆、地平线轮廓。
- **地形与视域**：DEM 计算地平线轮廓，与画面远山比对；检查最佳点能否看到画面中的地标。
- **太阳/阴影**：用 SunCalc 类工具，用推断的录音 UTC 时间检查阴影方向与长度。
- **环境声**：教堂钟声、火车鸣笛、广播、特定鸟类、道路噪声强弱与距离道路的一致性。
- **镜像判别**：单事件直线飞越的两个镜像候选，常可由"飞机从画面左还是右飞过"、地形遮挡、道路位置区分。
- **立体声扩展**：双声道录音可用通道间相位/时间差（GCC-PHAT）估计飞机方位随时间的变化——
  方位在 CPA 前后翻转的方向直接打破镜像对称（本 skill 未实现自动化，需手工分析；麦克风朝向未知时只能判左右）。

## C. 置信度量表

| 等级 | 条件 |
|---|---|
| **高** | 两事件（交叉角 ≥ 25°）或单事件 + 时钟 ±2 s 且非镜像；追踪检验通过；margin ≥ 0.15；叠加三段贴合；热图半径 ≤ 150 m；有至少一项独立佐证 |
| **中** | 满足声学条件但无独立佐证；或 margin 0.05–0.15；或热图半径 150–600 m |
| **低** | 镜像未排除、条带 > 600 m、margin < 0.05、叠加只贴一段、或 ADS-B 覆盖可疑 |
| **不可用** | 拟合 implausible、漏斗为空、`NO CONSISTENT SITE`、`DEGENERATE`、或多架飞机得分不可区分 |

报告中的位置写法：
- 高/中：坐标 + "约 ±R m（0.9 得分区域）"。
- 条带：两端坐标 + 宽度 + 方位，说明原因（"时钟 ±30 s，沿航迹方向不可分辨"）。
- 镜像：两个坐标并列，说明需要的判别信息。

## D. 常见误判来源

- 同一航线上多架次（训练机绕场、航校）→ 错误航班也能匹配；靠第二事件或时间区分。
- 地面车辆/无人机/船舶的音调（v < 25 m/s 或 d < 150 m）。
- 录音被剪辑：两事件间的时间差被改变 → 双事件漏斗失效。看剪辑痕迹（背景噪声突变、门控图案断裂）。
- 平台变速（1.25× 播放）或采样率错误 → 所有频率按比例偏移，v、d 不变但 ΔT 和时长被缩放。检查哼声是否仍在 50/60 Hz。

## E. 合成盲测基线（`selftest`，6 个随机种子）

场景：50–70 km 区域、4 h、约 70 架次（45 螺旋桨 + 25 喷气），录音 ~24 min 含两次螺旋桨飞越（间隔 ~915 s），
粉红噪声 + 电源哼声 + 说话 + 喷气机；事件 2 的飞机在 CPA 前加速、CPA 后爬升（故意让线性拟合有偏）。

| 模式 | 结果 |
|---|---|
| 两事件、时间未知 | 误差 24–53 m（5/6）；1 例两航迹交叉角仅 3°，误差 477 m，但真值在报告的 0.9 区域（半径 849 m）内并给出警告 |
| 单事件、时钟 ±2 s，CPA 后转弯的飞越 | 23–96 m（6/6） |
| 单事件、时钟 ±2 s，直线飞越 | 6–213 m（4/6）；另 2/6 镜像侧得分略高，真值为被标记的镜像备选 |
| 单事件、时钟 ±30 s | 条带长 2–5 km，真值均在条带内 |

每个种子的两事件答案都通过追踪检验（稳健 RMS 为拟合自身的 1.0–1.9 ×）。

这是理想化合成数据（ADS-B 无缺失、无风、无多径），真实素材的误差应预期更大；它说明的是**管线正确性和不确定度报告的诚实性**，
不是真实世界精度保证。修改代码后应重跑 `selftest --seed 7/11/23/42/101/2026`。

## F. 没有一致的地点时

两个事件没有候选能同时解释（`NO CONSISTENT SITE`，或只有叠加图只贴合一个事件的低分）时，有几种可能。本方法无法区分它们，请在报告中说明。

1. **两个事件不在同一地点**，或两段录音按错误的时间偏移拼接。确认录音确实在同一处，以及它们的时钟关系。
2. **某架飞机不在 ADS-B 数据中**：没有 ADS-B Out（美国大量低空 GA 不强制）、低空或地形遮挡收不到，或被 `--event-classes`、`--start/--end`、bbox 排除。此时每个事件单独仍能找到"匹配"的飞机（速度和距离相近的任何飞机都能贴合一条曲线），但没有一个点能同时解释两者。音频本身无法排除这种情况。
3. **地点在 bbox 或时间窗之外。** 放宽它们。
4. **追踪跟错了线**（另一条谐波、音乐、车辆）。逐个检查拟合叠加图。

下一步：已知时钟时把每个事件单独运行，比较各自的单事件条带位置。条带永不相交指向原因 1 或 2。在录音中寻找另一次飞越，或寻找能缩小区域的视觉线索。
